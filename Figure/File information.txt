#     meta      METABRIC
#     icgc      ICGC BRCA-EU
#     ispy      I-SPY2
#     matador   MATADOR
#     cheng     Cheng et al.
#     hatzis    Hatzis et al.
#     kao       Kao et al.
#     sjostrom  Sjostrom et al.

#     : XEG status matrix of the CCLE cell lines, gene x cell line

#     : PAM50 subtype and total number of XEGs of each patient in TCGA-BRCA,

### XEG PREDICTION MODEL ########################################################
#
# Summaries of the XGBoost model of Figure 2k and Supplementary Figure 12. The
# model itself is not stored. Every value is measured on held-out patients.
# They are produced by 01.Analysis/6.xeg.model.cross.validation.R.

# xeg.model.summary
#     : mean and standard deviation of the outer test AUROC across the 50
#       cross-validation folds, with the mean number of features selected
# xeg.model.feature.frequency
#     : the proportion of the 50 folds in which each candidate feature was
#       selected. Features reaching 0.5 form the final feature set.
# xeg.model.univariate.auc
#     : AUROC of a model built from each feature alone
# xeg.model.feature.evaluation
#     : gain, mean absolute SHAP value and AUROC drop on removal of each feature
# xeg.model.block.ablation
#     : AUROC drop when a whole feature category is removed
#
# The last three are averaged over the folds in which that feature was selected,
# and each carries the number of contributing folds.
